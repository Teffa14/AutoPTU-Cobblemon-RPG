# Meridian bastion-detail adaptation

Status: IMPLEMENTATION PROVENANCE / NON-CANON VISUAL REFERENCE
Date: 2026-08-26

A user-provided Minecraft reference image labelled `Homestead Bastion` was used as a composition and detail-density reference for the first OI-105 Meridian pass.

The source build is not copied block-for-block and no source asset is redistributed.

Transformed lessons used in Meridian:

- heavy masonry visually carries lighter upper construction;
- timber floors and galleries can cantilever beyond the masonry mass;
- dark roofs read better when they have several eave/ridge layers instead of one flat cap;
- brackets beneath overhangs make structural depth visible at close range;
- narrow windows, shutters and frame changes create human-scale facade rhythm;
- balcony rails and small objects make upper floors read as usable space;
- lanterns work best when physically suspended from beams/eaves;
- small ridge finials materially improve distant silhouette;
- vegetation at the foundation softens structure/ground transitions;
- barrels, pots, scaffolding, composters and work objects should cluster where the building function justifies them rather than being scattered randomly.

Ouros adaptation:

The reference language is translated into a botanical/civic Gym. Meridian uses deepslate tile, dark oak, stone masonry, oxidized copper, glass and horticultural props. The west challenge roof becomes a keeper/observation pavilion rather than a residential bastion. Arena and atrium detailing reuse the same hierarchy without changing their institutional function.

Mechanical boundary:

All referenced forms are Minecraft presentation. Roofs, railings, masonry, screens, planters and props do not create PTU terrain effects or combat modifiers.
