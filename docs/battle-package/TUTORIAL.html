InstalaciónCrear comandoJugarProblemas

Alcance real: práctica 1 contra 1 contra un rival automático. Podés elegir especies disponibles en Cobblemon, pero sus modelos usan estadísticas de escenario y tres ataques propios. No es todavía cualquier modalidad PTU: no incluye PvP, captura, campaña, habilidades ni movimientos nativos.

01 / Instalá el paquete en un perfil separado

  1. Usá Minecraft Java 1.21.1, Java 21 y un perfil Fabric Loader 0.18.2 o posterior compatible con 1.21.1. Este ZIP no incluye Minecraft ni el instalador de Fabric.
  2. Elegí una carpeta de juego nueva en tu launcher. No reemplaces las dependencias de tu COBBLEVERSE existente: ese modpack puede usar otra versión de Cobblemon.
  3. Extraé el ZIP y copiá su carpeta mods a la carpeta del nuevo perfil. Debe contener AutoPTU, Cobblemon 1.8.0, Fabric API y Fabric Language Kotlin. No agregues un segundo JAR de AutoPTU.
  4. Iniciá el perfil. Creá un mundo creativo, superplano, con comandos habilitados. Usá una zona llana y despejada: el comando no construye ni aplana el suelo.
  5. En multijugador, cliente y servidor necesitan los mismos mods; el jugador que inicia necesita OP. Los informes solo se envían a su dueño.

Para abrir el tutorial dentro de Minecraft:

/autoptu battle help

03 / Elegí → previsualizá → confirmá
    

  1. Presioná B para abrir las acciones. El turno del jugador espera tu decisión.
  2. Elegí Movimiento o una ficha de ataque. Hacé clic en una casilla válida del tablero.
  3. Elegí Previsualizar. El menú se cierra y el campo muestra la selección.
  4. Enter confirma esa selección; Backspace la cancela. Una previsualización vieja no puede confirmar una opción nueva.
  5. Mover consume Shift, pero permite atacar después. Un ataque confirmado pasa el control al rival tras resolverse. También podés usar Pasar turno.




Las flechas navegan por el tablero; Re Pág / Av Pág recorren las opciones exactas. Las teclas de batalla se pueden reasignar en Controles de Minecraft.

04 / Leé el HUD y terminá la partida
El panel con borde destacado identifica al bando activo. Los números muestran PS reales; la barra animada y la estela ámbar permiten ver cuánto bajaron. Ronda, preparación, impacto y resultado aparecen debajo.


H o /autoptu battle report abre el informe. Podés filtrar por bando y revisar daño, aciertos, fallos, críticos y desplazamientos. Se guarda el último informe de cada jugador, con 256 eventos recientes y totales completos.


/autoptu admin battle stop
Cierra tu sesión sin recompensas. Tras victoria o derrota, la limpieza es automática; después podés ejecutar otro comando de inicio. No podés tener dos sesiones propias simultáneas.


05 / Si algo no funciona


Fabric no inicia
Revisá Minecraft 1.21.1, Java 21, las cuatro dependencias del ZIP y JAR duplicados. No mezcles este paquete con Cobblemon 1.7.1.


El comando no existe
AutoPTU debe estar en el servidor también. En un mundo local, revisá que iniciaste el perfil Fabric correcto.


No tenés permiso
Habilitá comandos en el mundo o pedí OP al administrador. El tutorial se puede abrir sin OP, pero iniciar práctica lo requiere.


Especie desconocida
Usá su ID en minúsculas y sin espacios, no un apodo traducido. El generador no trae un catálogo: Cobblemon valida el ID.


La previsualización venció
Volvé a abrir el menú y elegí una opción actual. Los tokens de confirmación son temporales.


Los modelos se superponen con el terreno
Detené la sesión y elegí un espacio llano y despejado. El comando no altera los bloques.
